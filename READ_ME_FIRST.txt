04.고장비교
비교단위 선택을 제거했습니다. 기준 부서·라인·상세설비와 비교 부서·라인·상세설비를 VS 위아래 두 줄로 배치합니다. 기준 라인이 전체이면 부서별, 특정 라인과 상세설비 전체이면 라인별, 특정 상세설비를 고르면 상세설비별 실적을 비교합니다.
- 기준은 B7 부서, E7 라인, I7 상세설비입니다. 비교는 B9 부서, E9 라인, I9 상세설비입니다.
- 부서는 [공장] 팀 형식으로 구분합니다. 각 라인 목록은 자기 쪽 부서에 속한 라인만, 상세설비 목록은 자기 쪽 라인에 속한 항목만 표시합니다.
- 비교 부서가 전체이면 모든 공장·부서가 범위입니다. 특정 비교 부서를 고르면 그 부서만 범위가 됩니다.
- 비교의 전체는 현재 비교 수준의 각 대상을 개별 표시합니다. 기준이 특정 라인이면 비교 부서의 각 라인, 기준이 특정 상세설비이면 비교 범위의 각 라인·상세설비 실적을 보여줍니다.
- 상위 선택 변경 시 자기 쪽 하위 선택을 전체로 초기화합니다. 기준 수준이 얕아져 사용할 수 없어진 비교 하위 선택도 초기화합니다. 다른 쪽 부서 선택은 유지합니다.
- 상세설비는 라인 선택 후 선택합니다. 기준이 부서 수준이면 비교 라인은, 기준이 상세설비 수준이 아니거나 비교 라인이 전체이면 비교 상세설비는 회색으로 표시하며 선택할 수 없습니다.
- 같은 라인의 서로 다른 상세설비는 두 행으로, 완전히 같은 대상은 한 행으로 표시합니다. 동명 라인은 부서 접두어로 구분합니다.
- 표에는 공장·팀·라인·설비군·상세설비·건수·정지시간·기준 대비 차이를 표시합니다. 표의 설비군 필터를 유지하며 상단 조건 변경 시 표 필터는 해제합니다.
- 차트 제목은 부서별·라인별·상세설비별로 바뀝니다. 각 차트는 지표별 내림차순 TOP 10, 아래 표는 전체 항목을 표시합니다.
- 자동 초기화·항목 활성화·결과 행 접기는 XLSM에서 매크로를 허용해야 작동합니다. 일반 XLSX에서는 조건 변경 후 하위 선택을 직접 확인해야 합니다.

02.팀별 주요이슈: 공장·팀 → 라인 → 상세설비 → 세부부품 → 표준화 이력 탐색
03.월별 주요이슈: B8 조회 단위, D8 일별 조회할 월, J8 세부부품, L7:L8 더블클릭 월별 복귀

활성화된 검색형 필터 셀은 선택하면 검색창이 열립니다. 후보를 선택해야 반영되며 Esc로 취소할 수 있습니다.
