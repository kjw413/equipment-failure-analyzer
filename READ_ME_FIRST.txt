설비 고장 분석기 v1.9.0 - 화면 구성 개선과 표에서 바로 수정

1. Python이 있는 Windows PC: START.bat 실행.
2. Python이 없는 PC: EquipmentFailureAnalyzer_v1.9.0.exe 실행.
   EXE는 Python 설치 PC에서 BUILD_EXE.bat으로 만들 수 있습니다.
3. Excel 파일 등록 후 [표준화 + 분석 실행]을 누르세요.
4. 부품·증상 조건에 일치하는 규칙으로 분류하며, 이전 점수 설정값은 사용하지 않습니다.
5. [검토필요]에서 원문과 분류 근거를 확인하고 표의 셀을 직접 수정하세요.
   수정할 셀은 더블클릭하거나 F2를 누릅니다. 대·중·소분류를 모두 선택하면 저장합니다.
   노란 셀은 선택 중이며 Esc로 취소합니다. 유형조합 셀에서 단일·복수 분류를 편집합니다.
   일자·정지시간·고장대상·제품은 입력 후 Enter 또는 다른 셀 이동으로 저장합니다.
6. [Excel + PDF 생성]으로 최신 결과를 저장하세요.

제외·부정·예정 표현을 걸러낸 뒤 구체적인 부품명, 고장·교체 근거, 인과관계, MES 단서로 후보를 해소합니다.
후보 충돌이 해소되지 않거나 대안·독립 복수 고장이 적혀 있으면 검토필요로 남깁니다.
복수 고장은 구성 유형의 조합으로 잠정 집계합니다. 유형조합 셀의 편집 목록에서 실제 고장 유형들을 복수 확정하세요. 건수·정지시간은 기록당 한 번만 합산합니다.
대분류·중분류·소분류는 목록에서 선택합니다. 사람이 확정한 분류가 자동 판정보다 우선합니다. 시간만 고치면 분류는 확정되지 않습니다.
새 운영 목록을 자동분류와 계층별 선택 목록에 적용합니다. 소분류는 구체적인 부품 종류이며 현상·조치와 구분합니다.
기본 목록은 대분류 6개·중분류 58개·소분류 237개이며, 기본 부품 규칙은 237개입니다.
기존 수동확정값은 해당 기록에서 그대로 유지합니다. 목록 밖 기존 사용자 규칙은 보존 후 비활성화하고, 목록 안 사용자 규칙은 유지합니다.
전환 전 설정을 백업합니다. 같은 운영 카탈로그에서는 직접 비활성화·삭제한 새 규칙을 되살리지 않습니다.
v1.8.0 전환 후에는 이전 EXE로 새 규칙을 읽을 수 없으므로 START.bat 또는 v1.8.0 이상 EXE를 사용하세요.
기존 설정·설비명·수동 보정은 사용자 설정 폴더에 유지됩니다.
화면 탭: 종합현황 / 검토필요 / 상세분석 / 설비별 유형순위 / 부품별 포함 건수 / 월별 부품 추이 / 그래프.
상세분석에서 설비별·라인별·유형별 분석과 전체 기록 · 수정·교차분석·원본 확인을 선택합니다.
저장하면 화면 분석을 갱신합니다. Excel·PDF는 다시 생성해야 최신 보정값이 반영됩니다.
