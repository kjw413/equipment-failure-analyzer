설비 고장 분석기 v1.15.0 - 1순위 대표 자동선택

1. Python이 있는 Windows PC에서는 START.bat을 실행합니다.
2. Python이 없는 PC에서는 EquipmentFailureAnalyzer_v1.15.0.exe를 실행합니다.
3. 원본 Excel을 등록하고 [표준화 + 분석 실행]을 누릅니다.
4. 고장 분야 / 상세설비·모듈 / 세부 부품 / 고장 현상을 선택합니다.
   부품군은 부품 종류를 찾는 탐색 기준이며 선택한 부품에 따라 표시합니다.
   예: 기계 / 컨베어 / 베어링(종류 미상) / 마모, 부품군 베어링·부싱.
   네 분류축은 독립 선택합니다. 다른 축을 바꿔도 기존 선택을 유지합니다.
5. 교체·수리·조정 등 조치는 별도 항목에 표시합니다.
   단일 부품의 조치만 기재된 기록은 부분분류로 보존하며 고장 현상을 추정하지 않습니다.
   종합현황의 완전 자동분류·부분 자동분류·검토 대상을 각각 확인하세요.
   원문에 없는 정보는 미기재로 표시하며, 부분분류에서 조치만 고칠 수도 있습니다.
6. 여러 부품·현상·설비가 기록되면 근거 있는 1순위 후보를 이력 대표로 자동 선택합니다.
   순위는 정확도나 확률이 아니며, 다른 실제 고장이 없다는 뜻이 아닙니다.
   원문과 모든 후보는 보존합니다. 의심·대안·미등록 다른 고장 등은 검토에 남깁니다.
   [검토필요]에서 남은 보호 사유와 후보 근거를 확인하고 분류를 선택합니다.
   선택은 메모리의 확정 대기로 보관하고 [표준화 + 분석 실행]에서 일괄 저장합니다.
   프로그램을 닫으면 아직 확정하지 않은 선택은 사라집니다.
7. [Excel + PDF 생성]으로 분석 Excel, PDF와 원본 검토표시 사본을 저장합니다.

상세설비는 원문의 고장·조치 문맥과 비가동코드(중)로 식별합니다.
근거가 없으면 상세설비 미상으로 남깁니다. 등록 설비명·라인명과 구분합니다.
본체만 명시된 기록은 세부 부품 미기재로 표시합니다.
부품 미기재·제품·자재 대상과 검토 후보는 실제 부품 건수에서 제외합니다.
전체 고장 건수와 정지시간은 이력당 한 번만 합산합니다.
차단기 떨어짐은 보호장치 동작으로 처리하고 원인을 과부하로 추정하지 않습니다.
손상·파손은 통합하고 마모·부식, 냉매·냉각수, 설비·부품은 구별합니다.
종류가 없는 부품은 종류 미상으로 남기며 구체적인 종류를 추정하지 않습니다.

기존 v3 수동확정값은 계속 적용합니다. 이전 스키마 수동확정은 재검토 후보로 보존합니다.
사용자 설비명·보정·규칙은 사용자 설정 폴더에 유지하며 전환 전 설정을 백업합니다.
새 대표 자동선택 정책은 v1.15.0 이상으로 실행해야 합니다. 현재 규칙은 schema 7입니다.
schema 7 지원 이전 EXE는 이전 판정 정책으로 동작하며, schema 7 미지원 버전은 규칙 읽기가 차단됩니다.
인터넷 연결이나 외부 AI 없이 PC에서 처리합니다. 입력 원본은 변경하지 않습니다.
