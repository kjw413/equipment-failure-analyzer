# 출력 Excel 시트 검수와 통폐합 내역 - v1.13.0

검수일: 2026-11-09 / 단일 최종분류: 2026-11-10 / 부품군·별도 조치: 2026-11-12

기존 18개 시트를 설비관리자의 업무 흐름에 맞춰 기본 11개로 통합했습니다. 분석 대상에 제품 자료가 있으면 `12_제품교차분석`을 추가하여 12개가 됩니다. 개별 시트의 탭 수를 줄이면서 전체 고장이력, 원본 대조 정보, 분류 근거와 분석 기준을 유지합니다.

이 구조는 프로그램에서 이후 생성하는 보고서에 적용됩니다. 입력 원본과 이미 저장된 보고서는 자동으로 수정하지 않습니다. 기존 보고서에서 새 구조가 필요하면 같은 자료와 분석 조건으로 다시 생성합니다.

기존 `07_교차분석`의 지표도 보존하도록 새 `02_설비별분석`의 유형표에 최대정지(분)(J열), 전체분석 건수 비중(K열), 전체분석 시간 비중(L열)을 함께 표시하며, 기존 C·F열의 건수·시간 비중은 해당 설비 안의 건수·시간을 분모로 사용합니다.

`11_기준정보`의 부품 식별 규칙은 긴 조건식의 자동 줄바꿈을 끄고 표시하므로, 전체 내용은 해당 셀을 선택한 뒤 Excel 수식 입력줄에서 확인합니다.

화면·보고서의 최종 분류는 고장 분야 / 상세설비·모듈 / 세부 부품 / 고장 현상입니다. 부품군은 세부 부품에서 표시하고 조치는 별도 열에 보존합니다. `11_기준정보`의 부품 식별 규칙은 내부 카탈로그의 분야 / 부품군 / 세부 부품 종류를 사용하며, 이 내부 경로로 부품을 식별한 뒤 원문의 현상을 연결합니다. 교체·정비 등 조치는 고장 현상으로 넣지 않습니다. 미확정 분류는 빈칸으로 두고 판정은 상태·사유에 표시합니다.

## 권장 열람 순서

1. **보고 전 검수:** `09_검토품질`에서 검토 기록을, `11_기준정보`에서 기간·공장·팀·누락·분류 집계를 확인합니다. 수정할 사항은 프로그램에서 보정하고 보고서를 다시 생성합니다.
2. **주간·월간 정비 회의:** `01_종합현황` → `02_설비별분석`·`03_라인별분석` → `04_유형별분석` 순서로 관리 대상과 개선 과제를 정합니다. 건수 Pareto는 반복 문제, 정지시간 Pareto는 손실 문제를 보는 데 사용합니다.
3. **예방정비 검토:** `05_기간별추이`와 `06_부품별분석`을 보고 증가 시기와 반복 부품을 확인합니다. 부품 포함 기록 수는 교체 수량·재고 소요량과 다르므로 정비 이력을 함께 봅니다.
4. **개별 사건 점검:** `07_고장이력`의 상위 N건 → `08_부품증상상세` → `10_원본데이터`와 원본 검토표시 사본 순서로 추적합니다.
5. **기준·제품 조건 점검:** `11_기준정보`에서 집계·분류 기준을 확인하고, 제품 자료가 있으면 `12_제품교차분석`으로 비교 범위를 넓힙니다.

## 합치지 않은 자료의 기준

`04_유형별분석`과 설비별 유형순위는 한 고장이력에 최종 분류 하나만 반영합니다. `실린더 및 베어링 손상`처럼 후보가 여럿인 기록은 최종 분류를 비워 두고 검토 후보로 보존합니다. 원문과 후보 순위·근거를 확인한 사용자가 하나를 선택해야 합니다. 첫 번째 후보를 임의로 집계하지 않습니다.

`06_부품별분석`은 최종 단일 부품이 정해진 고장만 한 번 집계합니다. 미확정·미일치·분류 없는 이력, 세부 부품 미기재와 제품·자재 대상은 실제 부품 건수에서 제외하지만 비율의 분모인 전체 고장기록과 전체 정지시간에는 보존합니다. 따라서 부품 비율 합계는 100%보다 작을 수 있습니다.

`07_고장이력`과 `08_부품증상상세`는 모두 고장이력당 한 행입니다. 08에는 미확정·미일치·분류 없는 이력도 포함하며 최종 분류가 없으면 빈칸과 검토 상태로 구분합니다. `10_원본데이터`는 분석에서 제외한 비가동과 원본 추가 열까지 대조할 수 있는 자료이므로 독립 시트로 유지합니다. MES의 생성·수정 사용자 열은 기존 방침대로 보고서에 포함하지 않습니다.

[검토필요]에서 추천 후보 하나를 선택하거나 독립 목록에서 고장 분야·상세설비·세부 부품·고장 현상을 직접 선택할 수 있습니다. 검토가 남아 있어도 Excel·PDF·원본 검토표시 묶음을 저장합니다. 09_검토품질은 원본 행부터 후보 규칙까지 핵심 22개 열만 표시하며 별도 정답·메모 열과 하단 품질 영역을 두지 않습니다. 대분류(분야)·상세설비·세부 부품·소분류(고장 현상)에 정답을 작성해 규칙 보완 자료로 전달할 수 있으며, Excel 수정값은 프로그램에 자동 반영되지 않습니다. 이력 ID·상세 근거는 07_고장이력, 품질 집계·분석 조건은 11_기준정보에 보존합니다. 프로그램의 최종 분류는 목록에서 하나만 선택합니다.

## 해석과 재생성

- 건수·정지시간은 입력 기록에 대한 집계입니다. 생산량·가동시간·실수리시간 없이 고장률, MTBF, MTTR나 제품별 고장 위험을 계산하지 않습니다.
- 검토필요 기록도 집계에 포함되므로 미확정 분류의 영향을 `09_검토품질`과 함께 설명합니다.
- 수식으로 연결된 집계 칸은 `07_고장이력`을 참조합니다. Excel에서 값을 바꾸더라도 부품별 표·분류 상세·검토 목록·차트 등 생성 시점 자료가 모두 갱신되지는 않습니다. 프로그램에서 보정한 뒤 보고서를 다시 생성해야 일관된 결과를 얻습니다.
- `11_기준정보`는 보고서를 생성할 때 적용한 설정입니다. 보고서 안의 규칙이나 설비명을 고쳐도 프로그램의 사용자 설정은 바뀌지 않습니다.
- 원본과 기존 보고서는 보존합니다. 새 보고서와 이전 보고서를 비교할 때는 기간·분석 범위·설비 분석 기준·공장·팀·중복 제외 조건을 먼저 맞춥니다.


## v1.14.0 자동분류 범위 표시

01_종합현황, 11_기준정보와 PDF에 완전 자동분류·부분 자동분류·자동처리 합계를 나눠 표시합니다. 일부 분류축이 원문에 없으면 확인된 항목을 부분분류로 보존하며 07_고장이력의 미기재 분류 항목 열에서 부족한 정보를 확인합니다. 부분분류도 실제 부품이 확인되면 부품 집계에 포함합니다. 후보 충돌·미일치와 시간·일자 등 품질 문제는 실제 검토 목록에 남깁니다.
