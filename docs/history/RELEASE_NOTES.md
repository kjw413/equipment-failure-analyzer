## v1.32.0 (2026-11-19)

비교단위 선택을 제거했습니다. 기준 부서·라인·상세설비와 비교 부서·라인·상세설비를 VS 위아래 두 줄로 배치합니다. 기준 라인이 전체이면 부서별, 특정 라인과 상세설비 전체이면 라인별, 특정 상세설비를 고르면 상세설비별 실적을 비교합니다.

양쪽 종속 목록·상위 변경 초기화·다른 쪽 부서 보존·동명 라인 구분·동일 대상 중복 제거를 적용합니다. 표와 차트는 선택 깊이에 맞게 갱신합니다. Excel 1개와 PDF 1개의 통합 출력, 검토·분류현황과 색칠된 원본 별첨은 유지합니다.

# v1.31.0 Excel/PDF 두 파일로 통합 (2026-11-19)

- 동일 상세설비 비교·기준정보 별첨을 제거했습니다. 04.고장비교는 기존 부서 전체·선택 공장 내 라인/상세설비 비교 범위를 유지합니다.
- 별첨. 검토·분류현황에 분류 상태별 건수·검토 사유별 색상 안내·검토 대기 목록을 모았습니다. 원본 행 번호 링크로 색칠된 원본 별첨에 이동합니다.
- 별첨. 원본 검토표시는 분석 입력 시트의 행열·값·서식·기존 메모를 보관하며 검토필요 행 A:X의 색상과 사유 메모를 추가합니다. 원본 수식은 저장된 계산값으로 보관하고, 캐시가 없으면 수식 문자열로 남깁니다.
- 외부 원본 검토표시 파일과 열기 버튼을 제거했습니다. 결과 Excel 1개와 PDF 1개를 함께 저장하며 실패 시 두 출력 모두 복구합니다. 입력 원본은 변경하지 않습니다.
- 기본 표시 시트는 8개이며 제품 자료가 있으면 제품교차분석을 추가합니다. 주요 4개 시트의 배치·틀 고정 제거·천 단위 표시와 기존 분석·분류 결과는 유지합니다.

# v1.30.3 부서 전체·라인 상세 비교 범위 정리 (2026-11-19)

- 부서 모드는 부서 전체 고장 건수·정지시간을 비교합니다. 상세설비 두 칸을 비활성화하고, 부서 집계 수식에서도 상세설비 조건을 제거했습니다.
- 라인 모드에서만 기준·비교 상세설비를 선택합니다. 라인 전체 비교와 동일 라인의 서로 다른 상세설비 비교를 유지합니다.
- 부서 전환 시 상세설비는 전체로 초기화합니다. 수동으로 남은 상세설비 값도 부서 집계나 중복 행 생성에 영향을 주지 않습니다.
- 사진 배치·회색 비활성 표시·틀 고정 제거·천 단위 구분기호는 유지합니다.

# v1.30.2 전사 차트 숫자 표시 원칙 (2026-11-19)

- Excel의 모든 분석 차트에서 데이터 레이블·숫자 축을 #,##0으로 통일하고 셀의 일반 서식에 다시 연결되지 않도록 명시했습니다. 날짜·백분율 서식은 보존합니다.
- PDF와 프로그램 차트의 숫자 축에도 정수 천 단위 구분기호를 적용합니다. 원본 수치·계산 정밀도·차트 배치와 필터 동작은 유지합니다.
- 위 원칙을 사용 안내에 기록해 향후 생성 보고서에도 적용합니다.

# v1.30.1 사진 배치 복원·틀 고정 제거 (2026-11-19)

- 결과 보고서의 모든 시트에서 틀 고정을 제거했습니다. pane과 잔여 selection pane 참조도 함께 제거합니다.
- 사진의 A6:H7 위치·병합·테두리를 유지합니다. 기준·비교 부서와 기준·비교 라인 칸을 모두 표시하고 해당 단위만 활성화하며, 비활성 칸은 회색으로 표시합니다.
- 추가 상세설비 두 칸은 기준 D8:E8·비교 G8:H8에 정렬했습니다. 기존 독립 집계·목록 연동은 유지합니다. 새 상세설비 표 열 너비도 기존 열과 같게 맞췄습니다.

# v1.30.0 기준·비교 대상과 상세설비 선택 (2026-11-19)

- 비교단위는 부서·라인 두 가지의 일반 드롭다운으로 변경했습니다. 검색창은 열지 않으며 해당 단위의 기준·비교 항목만 활성화합니다.
- 기준·비교 대상을 두 줄로 배치하고 상단 설비군 필터를 제거했습니다. 기준 상세설비와 비교 상세설비를 독립적으로 선택하며 각 목록은 선택 대상에 속한 항목으로 제한합니다.
- 비교 대상 전체는 기존 전체 비교, 특정 대상은 기준·비교 대상만 표시합니다. 라인 후보는 기준 라인 공장 전체 팀에 속한 라인으로 제한합니다.
- 같은 라인의 서로 다른 상세설비도 두 행으로 비교하며, 완전히 같은 대상·상세설비 조합은 중복 표시하지 않습니다. 표에 각 행의 상세설비를 추가하고 차트 항목명에도 선택한 상세설비를 표시합니다.
- 설비군 열과 표 필터, 독립 내림차순 차트, 병합 입력칸의 네 변 테두리, 원본 분류·판정·정지시간 보존을 유지합니다.

# v1.29.1 비교 단위별 필터 표시·테두리 보완 (2026-11-19)

- 부서 모드에는 기준 부서·팀, 라인 모드에는 기준 라인을 표시합니다. 비교단위·공장·설비군·상세설비는 공통입니다.
- 비활성 필터는 캡션·값·테두리·드롭다운을 숨기고 검색과 직접 변경을 막습니다. 모드 전환 시 다시 복원합니다.
- 라인 모드에서 공장을 명시적으로 선택합니다. 공장 전체 라인 비교와 설비군 필터·기준 라인 차이 계산은 유지합니다.
- 병합 입력칸과 상세설비 상하 배치의 테두리를 네 변 모두 그려 끊김과 남은 선을 제거합니다. 클립보드를 사용하지 않고 서식을 갱신합니다.
- 일반 XLSX는 모든 필터를 정적으로 표시합니다. 분류·표준화·고장이력·정지시간은 변경하지 않습니다.

# v1.29.0 고장비교 통합·수정 양식 반영 (2026-11-19)

- 제공된 수정 파일의 고장비교 시트를 반영하고 팀간비교는 제거합니다. 주요 시트의 이동한 필터·표·차트 참조를 연결합니다.
- 부서 비교를 유지하고 라인 비교는 선택 공장의 모든 팀·모든 설비군 라인을 기본으로 표시합니다. 기준 라인은 증감 계산에만 사용합니다.
- 설비명 변환 설정의 저장된 설비군으로 표와 차트를 필터링하며, 표에도 라인·설비군 열과 기본 Excel 필터를 제공합니다. 두 차트는 각각 내림차순 TOP 10, 표는 전체 항목입니다.
- 비교 단위·공장·설비군 변경 시 하위 선택을 초기화하고 표 머리글 필터를 해제합니다. 월별 시트의 조회 월은 D7, 세부부품은 F7로 이동합니다.
- 분류·표준화·판정·입력 원본은 변경하지 않습니다.

# v1.28.0 동일 상세설비 비교·순위 막대·기간별추이 정리 (2026-11-18)

별첨 두 개가 같은 필터로 거의 같은 결과를 보여 주던 문제를 정리했습니다. 개선 대상 선정은 02.팀별 주요이슈, 같은 설비의 라인 간 비교는 별첨. 동일 상세설비 비교, 시기별 변화는 04.월별 주요이슈에서 확인합니다. 별첨. 라인별분석은 02와 기능이 겹쳐 삭제했습니다.

별첨. 동일 상세설비 비교에서는 상세설비를 먼저 고르고, 필요하면 세부부품을 고른 뒤 공장·팀으로 비교 범위를 좁힙니다. 1위·2위·기타로 표시되던 도넛 차트 대신 건수·정지시간 TOP 10 가로 막대에 실제 라인명과 수치를 표시합니다. 아래 표에는 모든 라인을 공장·팀과 함께 나열하며, 비중은 현재 선택 범위 전체 대비입니다. 매크로 보고서에서 막대나 표의 라인을 더블클릭하면 02.팀별 주요이슈의 해당 라인 세부부품 순위(세부부품 선택 시 고장이력)로 이동합니다.

별첨. 기간별추이는 필터 없이 전체 기간만 보여 주어 04.월별 주요이슈와 역할이 겹쳐 삭제했습니다. 04에서는 월 차트의 실적이나 표의 월을 더블클릭하면 해당 월의 일별 실적으로 내려가고, '월별로 돌아가기'를 더블클릭하면 돌아옵니다. 한 번 클릭으로는 화면이 바뀌지 않습니다.

# v1.27.0 조직별 차트 정렬·월별 주요이슈 드릴다운 (2026-11-18)

03.팀간 비교의 건수·정지시간 차트는 각각 큰 값부터 위에서 아래로 정렬합니다. 두 차트의 조직 순서는 지표에 따라 달라지며, 표의 기준 부서 대비 계산은 유지합니다.

04.월별 주요이슈는 기존 공장·팀·라인·상세설비·세부부품 조건으로 월간 실적을 표시합니다. 월 차트의 실적을 한 번 클릭하거나 표의 월을 더블클릭하면 해당 월의 일별 실적으로 내려갑니다. B7은 조회 단위, F7은 일별 조회할 월이며, I7을 더블클릭하면 월별 화면으로 돌아갑니다. 클릭 탐색에는 매크로 허용이 필요하고 일반 XLSX에서는 B7·F7의 목록을 사용합니다.

날짜 미상은 추이에서 제외합니다. 기록이 없는 날은 0, 기록은 있으나 정지시간이 모두 미기재인 날의 시간은 빈칸입니다. 일별 증감은 실제 전일·전년 동일 날짜 기준이며 월별 비교 기준은 유지합니다.

11월 17일 수정 양식의 청색·녹색 순위표, 주요 시트의 21pt 행 높이와 병합·차트 서식을 함께 반영합니다. 정지시간은 정수로 표시하며 분류·표준화와 저장 수치는 보존합니다.

# v1.25.0 전체 항목 표·정수 정지시간 (2026-11-17)

차트가 있는 분석 시트는 차트를 위에, 전체 항목 표를 아래에 표시합니다. 팀별 주요이슈 표는 선택 범위의 라인·상세설비·세부부품을 모두 표시하고, 선택형 별첨 표도 전체 항목을 표시합니다. TOP 가로 막대는 가장 큰 값이 위에 오며, 정지시간은 소수점 없이 분 단위 정수로 표시합니다. 원본 수치와 계산 정밀도는 보존합니다.

검색·드릴다운·비교·전월/전년 차이·차트의 참조 범위를 새 표 위치로 연결합니다. 입력 원본과 분류 규칙은 보존합니다.

## v1.23.0 11월 17일 리뉴얼 양식

새 시트명·서식·배치와 이동한 필터 위치를 적용합니다. 종합현황은 실제 라인의 건수·시간 TOP 10과 데이터 막대로 표시하고, 팀간 비교는 새 양식에 남긴 기준 부서·라인·상세설비 조건으로 재구성합니다. 삭제한 조건의 참조 오류와 빈칸에 남은 드롭다운을 제거합니다. 기본 글꼴까지 양식과 맞춰 열과 차트의 실제 표시 폭을 보존하며, 04 인쇄에는 오른쪽 차트 전체를 포함합니다. 별첨 7개는 새 양식의 머리글·치수·인쇄 열을 적용합니다. 분류·표준화 규칙은 변경하지 않습니다.

## v1.22.1 검색창 호출 오류 수정

한국어 Office의 내부 통합문서 모듈 이름과 XLSM의 codeName 불일치로 검색창을 여는 이벤트가 실행되지 않던 문제를 수정했습니다. 필터 셀 선택으로 검색창이 열리고 입력칸 아래의 후보가 입력 중 갱신됩니다. 실제 Excel의 셀 선택 이벤트·검색창 활성화·후보 표시·취소까지 확인했습니다.

## v1.22.0 입력 중 유사 후보 검색

기본 결과를 `.xlsm`으로 저장합니다. 필터 셀 선택 시 입력창과 후보 목록이 열리며, 정확·앞부분·포함·오타 유사도 순으로 후보를 제시합니다. 후보를 클릭하거나 ↑↓·Enter로 확정한 경우에만 정확한 해당 항목을 집계합니다. Esc 취소·후보 없음은 기존 선택을 유지합니다. 검색어 자체를 여러 항목의 합산 조건으로 사용하던 v1.21.0 동작은 제거했습니다. 일반 `.xlsx` 목록형 저장도 유지합니다. 보고서 생성이나 사용에 개발용 VBA 접근 설정은 필요하지 않습니다.

## 현재 기능 상태

- **분류:** 고장 분야 / 상세설비·모듈 / 세부 부품 / 고장 현상의 단일 최종 분류와 별도 조치. 네 축을 모두 확인하면 완전분류, 대표의 일부 항목만 미기재면 부분분류로 보존합니다. 근거 있는 1순위 대표를 자동 선택하고 의심·대안 등 보호 조건은 검토합니다. 전체 건수·정지시간은 기록당 한 번만 집계합니다.
- **검토:** 분류 선택은 메모리의 확정 대기로 유지하다가 [표준화 + 분석 실행]에서 한 번에 저장합니다. 프로그램을 닫으면 미확정 선택은 사라집니다.
- **분석:** 사용자 지정 설비명·설비군·공장·팀 기준 집계와 공장·팀 필터를 제공합니다.
- **출력:** Excel 기본 11개 시트(제품 자료가 있으면 12개), PDF, 원본 검토표시 사본을 함께 생성합니다. 미확정 분류가 남아 있어도 출력할 수 있습니다.
- **실행:** 외부 전송이나 LLM 없이 로컬 규칙으로 동작합니다. v1.15.0 단일 EXE와 안내서를 배포 ZIP으로 제공합니다. 이후 소스를 수정하면 실행파일을 다시 빌드해야 합니다.
