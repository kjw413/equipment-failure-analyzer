# 설비 고장 분석기 Release Notes

MES 비가동 Excel 자료를 고장 유형으로 분류하고, 설비·라인·기간별 건수와 정지시간을 분석하는 오프라인 Windows 프로그램의 기능 변화입니다.

**작성 기준일: 2026-11-13 · 현재 소스 버전: v1.16.0 · 최근 기능 변경: 2026-11-13**

## 최초 등록본의 기본 기능

최초 Git 등록본은 2026-10-15의 v1.5.0입니다. 그 이전 변화도 v1.2.0부터 변경 이력에 남아 있습니다.

- MES Excel 불러오기, 컬럼 매핑, 날짜·정지시간·표기 정리.
- 로컬 규칙에 따른 고장 분류, 검토필요 표시와 기록별 수동 보정.
- 설비·라인·유형·기간별 집계, Pareto·도넛 차트와 주요 고장 순위.
- 설비명 변환과 사용자 분류 규칙 관리, Excel 15개 시트와 PDF 보고서 생성.
- Windows GUI와 CLI 실행, 원본 보존과 사용자 설정 유지.

## v1.15.0 변경

- 명확한 단일 고장을 먼저 선택하고, 남은 복수 부품·현상·설비 후보에서 원문 고장 또는 완료 조치 근거가 있는 1순위를 이력 대표로 자동 선택합니다.
- 원문과 전체 후보를 보존합니다. 순위는 정확도나 확률이 아니며 대표 선택이 다른 실제 고장의 부재를 뜻하지 않습니다. 대표 부품만 이력당 한 번 집계합니다.
- 의심·대안, 미등록 다른 물리 고장, 불명확한 공동주어, 동일 명사의 동률 상충 규칙, 부품명만 있는 기록은 검토에 남깁니다. 상태는 규칙분류·부분분류를 유지하고 선택 사유에 1순위 대표 자동선택을 표시합니다.

## v1.14.0 변경

- 문맥에 따른 별칭·고장 표현을 보완하고, 미완료 작업·인명·장소명과 잘린 문장을 완료 조치로 읽는 오탐을 방지합니다.
- 완전 자동분류·부분 자동분류·실제 검토 대상을 구분하고 화면·Excel·PDF에 각각 표시합니다.
- 단일 대상의 확인된 정보는 보존하며, 미기재 현상·분야를 추정하거나 수기 재입력하도록 요구하지 않습니다.
- 부분분류에서 조치만 수정할 때 분류 재확정이 필요하지 않습니다. 출력 스키마 v3와 기존 v3 수기 확정값을 유지합니다.
- 실제로 명시된 단일 부품 고장은 후속 조치보다 우선하고, 복수 고장·명시적 대안·다른 설비·미등록 대상의 별도 고장은 검토 대상으로 보존합니다.

## 현재 기능 상태

- **분류:** 고장 분야 / 상세설비·모듈 / 세부 부품 / 고장 현상의 단일 최종 분류와 별도 조치. 네 축을 모두 확인하면 완전분류, 대표의 일부 항목만 미기재면 부분분류로 보존합니다. 근거 있는 1순위 대표를 자동 선택하고 의심·대안 등 보호 조건은 검토합니다. 전체 건수·정지시간은 기록당 한 번만 집계합니다.
- **검토:** 분류 선택은 메모리의 확정 대기로 유지하다가 [표준화 + 분석 실행]에서 한 번에 저장합니다. 프로그램을 닫으면 미확정 선택은 사라집니다.
- **분석:** 사용자 지정 설비명·설비군·공장·팀 기준 집계와 공장·팀 필터를 제공합니다.
- **출력:** Excel 기본 11개 시트(제품 자료가 있으면 12개), PDF, 원본 검토표시 사본을 함께 생성합니다. 미확정 분류가 남아 있어도 출력할 수 있습니다.
- **실행:** 외부 전송이나 LLM 없이 로컬 규칙으로 동작합니다. v1.15.0 단일 EXE와 안내서를 배포 ZIP으로 제공합니다. 이후 소스를 수정하면 실행파일을 다시 빌드해야 합니다.
