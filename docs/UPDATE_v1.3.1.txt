# v1.3.1 - 내림차순 정렬 수정

설비명 / 라인명 문자순이 기본 집계 순서를 덮어쓰던 화면 정렬 로직을 교체했습니다.
모든 분석표는 다음 기준으로 큰 값을 먼저 표시합니다.

- 설비 / 라인 / 유형 / 교차 / 기간별 분석표: 정지시간 합계 내림차순. 동일 시간이면 건수 내림차순.
- 설비별 유형순위: 설비는 정지시간 내림차순, 각 설비 안에서는 유형별 건수 내림차순.
- 고장상세 / 검토필요 / TOP 고장: 건별 정지시간 내림차순.
- Pareto: 건수 차트는 건수, 시간 차트는 정지시간 내림차순.
- 추이 그래프는 날짜순으로 유지합니다. 원본데이터는 원본 행 순서를 유지합니다.
- 합계 / 기타는 순위 집계와 구분하여 마지막에 표시합니다. 수치 없음은 하단에 배치합니다.

화면에서 열 제목을 눌러 정렬한 후 [큰 값순 정렬]을 누르면 기본 순서로 돌아갑니다.
불필요한 제품 관련 안내와 경고를 제거했습니다. 제품 정보가 없는 교차 / Pareto 구역은 빈 안내 없이 생략합니다.
설비명 자동저장, Excel + PDF 동시 생성, 원형 차트는 유지됩니다.

업데이트: 기존 프로그램을 닫고, 새 ZIP을 새 폴더에 모두 풀어 START.bat을 실행하세요.
기존 Windows 사용자의 설정 폴더를 지우지 않으면 설비명과 분류 설정이 유지됩니다.
이미 저장한 Excel / PDF는 자동 변경되지 않으므로 새 버전에서 다시 생성하세요.
